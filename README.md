## 简介
本仓库主要是关于瑞萨RA8系列芯片(包括1代480Mhz单核、2代1Ghz双核)多款型号的经验笔记，开发板给予瑞萨官网EK、和rtthread titan等。
项目均不是面向初学者，需要有一定的基础，初学者可以参考我的ra6m5系列、rzn2l、以及野火电子的fsp系列。
